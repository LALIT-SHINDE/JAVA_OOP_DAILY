# Advanced Class and Object in Java

## Overview

This project demonstrates the use of advanced Class and Object concepts in Java. It includes encapsulation, constructors, methods, object composition, and salary management using Employee and Department classes.

## Features

* Creation of classes and objects
* Default and parameterized constructors
* Encapsulation using private data members
* Getter methods
* Salary increment functionality
* Object composition (Department contains Employee object)
* Conditional statements for comparison

## Classes Used

### Employee Class

The Employee class stores:

* Employee ID
* Employee Name
* Employee Salary

Methods:

* displayDetails()
* increaseSalary()
* getSalary()
* getName()

### Department Class

The Department class stores:

* Department Name
* Employee Object

Methods:

* showDepartmentInfo()

### Main Class

The ClassObjectAdvanced class:

* Creates Employee objects
* Increases salary
* Displays employee information
* Creates Department objects
* Finds the highest-paid employee
