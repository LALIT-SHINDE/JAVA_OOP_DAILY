
Student Information File Handling in Java

Aim  
Write a Java program to implement student information in a file and perform operations on it.



Concepts Used

- File Handling
- FileWriter
- FileReader
- Exception Handling
- Scanner Class


Operations Performed

1. Accept student information from user
2. Store data into file
3. Read data from file
4. Display file contents


Classes Used

| Class | Purpose |
|---|---|
| Scanner | Accept user input |
| FileWriter | Write data into file |
| FileReader | Read data from file |
| IOException | Handle file errors |


File Used

text
student.txt


Program Flow

Input Student Data  
↓  
Write Data into File  
↓  
Close File  
↓  
Read File  
↓  
Display Data


Sample Output

Enter Student Name: Siddharth  
Enter Roll No: 101  
Enter Marks: 85  

Data Written Successfully

Reading File Data:

Student Name: Siddharth  
Roll No: 101  
Marks: 85

Result

The program successfully stores and reads student information using file handling in Java.
