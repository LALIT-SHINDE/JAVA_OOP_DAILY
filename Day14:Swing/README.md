Admission Enquiry Form Using Swing

Aim

To design an Admission Enquiry Form using Java Swing.

---

Software Requirements

- Java JDK
- VS Code / Eclipse / IntelliJ IDEA

---

Concepts Used

- Swing
- JFrame
- JLabel
- JTextField
- JTextArea
- JRadioButton
- JComboBox
- JButton
- ActionListener
- JOptionPane

---

Description

This project creates a GUI-based Admission Enquiry Form using Java Swing.

The form accepts student details such as:
- Name
- Gender
- Course
- Address
- Mobile Number

Two buttons are provided:
- Submit → Displays entered details.
- Reset → Clears all fields.

---

Output

The program displays a Swing window containing the admission enquiry form.

After clicking the Submit button, the entered information is shown in a dialog box.

---

How to Run

1. Save the file as:
   ```bash
   AdmissionForm.java
   ```

2. Compile the program:
   ```bash
   javac AdmissionForm.java
   ```

3. Run the program:
   ```bash
   java AdmissionForm
   ```

---

Conclusion

The Admission Enquiry Form was successfully designed using Java Swing with GUI components and event handling.
